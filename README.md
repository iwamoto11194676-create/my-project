# 営業利益かんたん計算

獲得件数・1件あたりの手数料・経費を入力して、売上合計、概算利益、利益率を確認できるシンプルなWebアプリです。入力するとすぐに計算結果が更新されます。

## 使い方

1. このリポジトリのファイルをパソコンにダウンロードします。
2. `index.html` をブラウザー（Chrome、Edgeなど）で開きます。
3. 獲得件数、1件あたりの手数料、経費合計を入力します。
4. 画面下部に計算結果が自動表示されます。

追加のソフトやサーバーは必要ありません。

## 計算式

- 売上合計 ＝ 獲得件数 × 1件あたりの手数料
- 概算利益 ＝ 売上合計 − 経費合計
- 利益率 ＝ 概算利益 ÷ 売上合計 × 100
- 売上が0円の場合、利益率は0.0%と表示します。

金額には3桁ごとのカンマを付けます。概算利益は、プラスなら緑、マイナスなら赤、0円なら青で表示します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力欄、計算結果、画面の文章を定義します。 |
| `style.css` | 色、余白、カード表示、スマートフォン向けレイアウトを設定します。 |
| `script.js` | 入力値を読み取り、計算・カンマ付き表示・利益の色分けを行います。 |
| `README.md` | アプリの使い方、計算式、各ファイルの役割を説明します。 |

## GitHub Pagesで公開する場合

1. GitHubでこのリポジトリを開き、**Settings** を選びます。
2. 左側の **Pages** を開きます。
3. **Build and deployment** の **Deploy from a branch** を選びます。
4. ブランチを `main`、フォルダーを `/(root)` にして **Save** を押します。
5. 数分後、同じPages画面に表示されるURLからアプリを開けます。
